One article, two ways to load it

Both pages show the same short guide to printmaking. Open each one, then use View Page Source and look for “Print the lighter ink first.”

HTML

The server sends the article with the page. You can read it with JavaScript turned off.

Open the HTML version →

JavaScript

The server sends an empty article container. A script fills it in after the page arrives.

Open the JavaScript version →

Why do they look the same?

View Page Source shows the HTML your browser received. Inspect → Elements shows the page after the browser has run its scripts. You’ll find the sentence in Elements on both pages.

A reader that only fetches HTML gets the article on the first page. A reader that runs the script can get it on both.
