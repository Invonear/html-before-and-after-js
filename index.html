Where to find the difference in your browser

Open each example in its own tab. Choose View Page Source and search for “Print the lighter ink first.” You’ll find it only in the HTML version. With JavaScript on, open the Elements panel in your browser’s developer tools. There you can find the sentence on both pages.

What about your site?

Take a product page. Can you find the product name, price and description in its source? If the price appears only after JavaScript runs, a crawler that skips the script will miss that price.
