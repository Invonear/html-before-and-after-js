Check the evidence yourself

Open either page above and choose View Page Source. Search for “Print the lighter ink first.” Only the HTML page contains that sentence. Now open Inspect → Elements with JavaScript enabled. The sentence is there on both pages.

Try it on a page you own

Pick a product page or an article. Check whether its name, main description and most useful link arrive with the HTML. If a script supplies them later, a reader that skips the script will miss them.
